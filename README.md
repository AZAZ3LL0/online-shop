# QZQ Merch Shop

[![gate](https://github.com/AZAZ3LL0/online-shop/actions/workflows/ci.yml/badge.svg)](https://github.com/AZAZ3LL0/online-shop/actions/workflows/ci.yml)

A single-collection merch shop: three t-shirts, crypto checkout, order tracking
in a Telegram bot, and an admin panel that runs both in a browser and as a
Telegram Mini App.

## English

### What it is

A complete storefront in one Go binary. A buyer picks a size, pays in crypto and
follows the order in a Telegram bot — no account, no registration, no login.
The seller gets an admin panel with revenue, traffic sources and price history.

Everything runs without a single external key: the payment provider and the bot
both have fakes behind the same interfaces, so the whole checkout works offline.

### Features

- **Storefront** — three product cards, hover flips the cover to the back print,
  size picker with `sold out` per size, server-rendered cart.
- **Checkout** — price snapshot per order, stock reserved for 30 minutes,
  NOWPayments invoice, IPN with signature verification and idempotent handling.
- **Telegram** — `Track in Telegram` deep link and QR, bot commands `/start` and
  `/status`, one outbox message per status change with retries.
- **Admin panel** — orders with filters and manual transitions, repricing with a
  reason written to `price_history`, stock editing, shipping / reservation
  window / shop pause as settings.
- **Analytics** — attribution per visit, funnel from visit to payment, traffic
  sources, revenue chart with price-change markers.
- **Mini App** — the same handlers under a narrow layout, themed from Telegram's
  `themeParams`, access by `initData` and a Telegram id allowlist.

### Stack

| Layer | Choice |
|---|---|
| Language | Go 1.25, stdlib `net/http` |
| Templates | [templ](https://templ.guide) compiled to Go |
| Frontend | Alpine.js 3 and Chart.js 4, vendored — no CDN |
| CSS | Tailwind 3 (standalone CLI) |
| Database | PostgreSQL 16 via `pgx/v5`, queries generated by `sqlc` |
| Migrations | `goose`, forward only |
| Payments | NOWPayments API v1, behind an interface with a fake |
| Deployment | Docker multi-stage, Caddy with automatic TLS |

### Quick start

Runs entirely on fakes — no domain, no provider keys, no bot token.

**Prerequisites:** Go 1.25+, Docker, `make`.

**1. Install the generators and linters**

```bash
make tools
```

**2. Get the Tailwind CLI** (`make tools` does not install it — it is a
standalone binary, not a Go module)

```bash
mkdir -p bin && curl -fsSL -o bin/tailwindcss \
  "https://github.com/tailwindlabs/tailwindcss/releases/download/v3.4.17/tailwindcss-macos-arm64" \
  && chmod +x bin/tailwindcss
```

Swap the asset for your platform: `tailwindcss-macos-x64`,
`tailwindcss-linux-x64`, `tailwindcss-linux-arm64`.

**3. Write your `.env`**

```bash
cp .env.example .env
```

Two values must be edited before anything starts:

```bash
APP_SECRET=<32+ random bytes, e.g. `openssl rand -hex 32`>
DATABASE_URL=postgres://app:app@localhost:5434/shop?sslmode=disable
```

Port **5434** is what the local database below is published on; the value
shipped in `.env.example` points at the Docker network instead.

**4. Build the stylesheet** — it is generated, not committed, so the site is
unstyled without this step

```bash
make css
```

**5. Start Postgres, apply migrations, load the demo data**

```bash
make db-dev && make migrate && make seed
```

**6. Run it**

```bash
make run
```

The shop is on **http://localhost:8080**. The seed gives you three products and
30 days of traffic, so the admin charts are not empty.

### Paying an order locally

With `PAYMENTS_PROVIDER=fake`, checkout redirects to a local payment page at
`/dev/pay/{order_number}` where you choose the status the provider "reports". It
sends a correctly signed IPN back to the application, so the whole path — order,
stock, status, outbox message — is exercised without any real money.

### Admin access

```bash
make migrate
go run ./cmd/app admin-password <login> [telegram-id]
```

Sign in at **http://localhost:8080/admin**. The optional Telegram id is the
allowlist entry that opens the Mini App for that account.

### Tests

```bash
make gate
```

Runs exactly what the pull request gate runs: `gofmt`, `templ generate`, `go
vet`, `golangci-lint`, `govulncheck` and `go test ./... -race`. Integration
tests use a real PostgreSQL through `testcontainers-go` — one container per
package, cloned per test — so Docker has to be running. The whole suite takes
about half a minute.

### Project layout

```

```

## Русский

### Что это

Магазин одной коллекции: три модели футболок. Покупатель выбирает размер,
платит криптой и следит за заказом в Telegram-боте — без личного кабинета,
регистрации и авторизации. Продавцу — админка с выручкой, источниками трафика и
историей цен.

Всё работает без единого внешнего ключа: у платёжного провайдера и у бота есть
фейки за теми же интерфейсами, поэтому чекаут целиком проходится офлайн.

### Возможности

- **Витрина** — три карточки, наведение переворачивает обложку на принт со
  спины, выбор размера с пометкой `sold out`, корзина рендерится на сервере.
- **Оформление** — снимок цены в заказе, резерв стока на 30 минут, инвойс
  NOWPayments, IPN с проверкой подписи и идемпотентной обработкой.
- **Telegram** — deep-link и QR «Track in Telegram», команды `/start` и
  `/status`, одно сообщение на каждый переход статуса с ретраями.
- **Админка** — заказы с фильтрами и ручными переходами, смена цены с
  обязательной причиной в `price_history`, правка стока, доставка / окно резерва
  / пауза магазина в настройках.
- **Аналитика** — атрибуция каждого визита, воронка от захода до оплаты,
  источники трафика, график выручки с маркерами смены цены.
- **Mini App** — те же хендлеры под узкий layout, цвета из `themeParams`
  Telegram, доступ по `initData` и allowlist Telegram-id.

### Быстрый старт

Полностью на фейках — ни домена, ни ключей провайдера, ни токена бота.

**Требуется:** Go 1.25+, Docker, `make`.

**1. Поставить генераторы и линтеры**

```bash
make tools
```

**2. Скачать Tailwind CLI.** `make tools` его не ставит: это отдельный бинарь, а
не Go-модуль

```bash
mkdir -p bin && curl -fsSL -o bin/tailwindcss \
  "https://github.com/tailwindlabs/tailwindcss/releases/download/v3.4.17/tailwindcss-macos-arm64" \
  && chmod +x bin/tailwindcss
```

Ассет под свою платформу: `tailwindcss-macos-x64`, `tailwindcss-linux-x64`,
`tailwindcss-linux-arm64`.

**3. Завести `.env`**

```bash
cp .env.example .env
```

Два значения надо поправить до первого запуска:

```bash
APP_SECRET=<32+ случайных байта, например `openssl rand -hex 32`>
DATABASE_URL=postgres://app:app@localhost:5434/shop?sslmode=disable
```

Порт **5434** — это тот, на котором публикуется локальная база из шага ниже;
значение из `.env.example` указывает на docker-сеть, а не на неё.

**4. Собрать стили.** Файл генерируется и не лежит в репозитории, без этого шага
сайт будет без оформления

```bash
make css
```

**5. Поднять Postgres, накатить миграции, залить демо-данные**

```bash
make db-dev && make migrate && make seed
```

**6. Запустить**

```bash
make run
```

Магазин на **http://localhost:8080**. Сид даёт три товара и 30 дней трафика,
чтобы графики в админке были не пустые.

### Оплата заказа локально

При `PAYMENTS_PROVIDER=fake` чекаут ведёт на локальную страницу оплаты
`/dev/pay/{номер_заказа}`, где ты выбираешь статус, который «сообщит» провайдер.
Она отправляет приложению корректно подписанный IPN, так что весь путь — заказ,
сток, статус, сообщение в outbox — проходится без реальных денег.

### Доступ в админку

```bash
make migrate
go run ./cmd/app admin-password <логин> [telegram-id]
```

Вход на **http://localhost:8080/admin**. Необязательный telegram-id — это запись
в allowlist, открывающая Mini App для этого аккаунта.

### Тесты

```bash
make gate
```

Гоняет ровно то же, что гейт на pull request: `gofmt`, `templ generate`, `go
vet`, `golangci-lint`, `govulncheck` и `go test ./... -race`. Интеграционные
тесты работают с настоящим PostgreSQL через `testcontainers-go` — один контейнер
на пакет, база клонируется на каждый тест, — поэтому Docker должен быть запущен.
Весь прогон занимает около полуминуты.
