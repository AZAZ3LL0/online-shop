# CLAUDE.md

Проект: Merch Shop (3 SKU), Go + templ + Alpine.js + Tailwind + PostgreSQL + Docker + Telegram Bot API. Соло-разработка, автор коммитов - `AZAZ3LL0 <sadrievsamat4@gmail.com>`.

Перед любой работой прочитай, в этом порядке:

1. **`tech.md`** - ядро: проект, стек, архитектура, схема БД, контракты, общие типы, UI-примитивы, стратегия тестов, правила кода и коммитов, Definition of Done, дорожная карта, решения по умолчанию. Источник истины.
2. **`SKELETON.md`** - только если скелет ещё не собран (чек-лист «скелет готов» в конце файла не пройден полностью).
3. **`TASKS.md`** - конкретная задача текущей сессии: карточка слайса, рабочий цикл, самопроверка перед мёрджем.

Правила без исключений:

- Подчиняйся `tech.md` дословно. Контракты, типы, роуты, статус-машина - не выдумываются.
- Не хватает контракта → остановись и выдай блок `CONTRACT GAP` (формат в `TASKS.md`). Не пиши код с выдуманным типом.
- Одна сессия = один вертикальный слайс из `TASKS.md` = одна ветка = один PR. Не расширяй объём задачи по ходу работы.
- Не трогай чужие домены и общие файлы (список в `SKELETON.md`, раздел «Защита общих файлов») без явного намерения, зафиксированного в задаче.
- Коммиты - английский, Conventional Commits, маленькие, по ходу работы, без следов нейросети (без `Co-Authored-By`, без `Generated with`, без упоминаний ассистента).
- Перед тем как считать задачу готовой - пройди чек-лист «Самопроверка перед мёрджем» в `TASKS.md`.
